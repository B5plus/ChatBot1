# ChatBot1

Humble AI Chatbot - A full-stack chatbot application with frontend and backend.

## Project Structure

- **frontend/** - Frontend application serving on port 3005
- **backend/** - Node.js/Express backend server on port 3001

## Getting Started

### Frontend
`bash
cd frontend
npm start
`
Runs on http://localhost:3005

### Backend
`bash
cd backend
npm start
`
Runs on http://localhost:3001

## Features

- AI-powered chatbot using OpenAI and Humble AI providers
- Real-time chat interface
- API endpoints for chat functionality
- CORS enabled for cross-origin requests
